## Error Messages

- PG name missing: Enter a PG name to continue.
- City missing: Enter the city where your PG is located.
- Area missing: Add the locality or area so users can understand where the PG is.
- Rent missing: Enter the monthly rent for this listing.
- Description too short: Add a little more detail so users can understand the property better.
- Photo upload failed: We could not upload this photo. Please try again.
- Unsupported photo: This file format is not supported. Upload a standard image file.
- Availability missing: Select the current availability before saving.
- Save failed: We could not save your changes right now. Please try again.
- Permission issue: You do not have access to update this listing.
- Network issue: We could not connect right now. Check your internet connection and try again.

## Success Messages

- Listing updated: Your listing details have been saved.
- Photos updated: Your listing photos have been updated.
- Availability updated: Availability has been updated for this listing.
- Photo removed: The selected photo has been removed.
