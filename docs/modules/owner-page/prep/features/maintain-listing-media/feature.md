## Summary

Maintain Listing Media lets an Owner add, replace, and remove PG photos so the listing reflects the current property clearly. This feature improves trust and inquiry quality by ensuring users can evaluate a listing visually before reaching out. It matters because outdated or missing photos weaken confidence even when the written details are correct.

## User Story

As an Owner, I want to manage listing photos so that users can see an accurate visual representation of my PG.

## Acceptance Criteria

- The owner can open the media section for an existing listing.
- The owner can add new photos to a listing.
- The owner can replace or remove outdated photos from a listing.
- After media changes are saved, the owner sees the updated photo set in the listing management experience.
- If a media action fails, the owner sees a clear error and can retry.

## Priority

High - Photo quality and freshness are central to user trust and listing evaluation.

## Dependencies

- create-pg-listing
