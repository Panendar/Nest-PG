## Summary

Create PG Listing lets an Owner add a new PG to the platform so it becomes discoverable to Users. This feature addresses the owner problem of low visibility by turning an offline property into a structured listing with the core information users need to evaluate it. It matters because the module cannot deliver supply freshness or owner participation without a reliable listing creation path.

## User Story

As an Owner, I want to create a PG listing so that users can discover my property and send relevant inquiries.

## Acceptance Criteria

- The owner can start a new listing from the owner-page module.
- The owner can enter the core listing details needed to describe the PG.
- The system saves the listing and returns the owner to a manageable listing state.
- If required listing information is missing, the owner sees clear validation guidance before the listing is created.
- After creation, the owner can continue to update media and availability from the listing management experience.

## Priority

High - This is foundational to owner participation and necessary for any discoverable inventory to exist in the platform.

## Dependencies

none
