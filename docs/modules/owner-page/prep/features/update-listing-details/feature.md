## Summary

Update Listing Details lets an Owner revise PG information after creation so the listing remains accurate and trustworthy for Users. This feature reduces stale or misleading property information by making routine edits practical within the owner workspace. It matters because discovery quality drops quickly when published listings no longer reflect the real property.

## User Story

As an Owner, I want to update my PG listing details so that users see accurate information before deciding whether to contact me.

## Acceptance Criteria

- The owner can open an existing listing and edit its current details.
- The system shows the latest saved listing information before changes are made.
- The owner can save revised details and see confirmation that the update succeeded.
- If required fields are cleared or invalid during editing, the owner sees validation guidance before changes are saved.
- Updated listing details become the latest version shown in owner management and user discovery contexts.

## Priority

High - Accurate listing information is essential to trust, discovery quality, and credible inquiries.

## Dependencies

- create-pg-listing
